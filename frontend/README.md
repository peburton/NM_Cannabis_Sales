# Frontend

A React + Vite dashboard that queries NM cannabis sales data entirely in the browser using DuckDB WebAssembly. No backend, no API calls at runtime — just static files and client-side SQL.

Live at: [https://project-es7vc.vercel.app/](https://project-es7vc.vercel.app/)

---

## How it works

Instead of a traditional API server, the dashboard loads two Parquet files from `/public/data/` and queries them using DuckDB WASM — a full DuckDB instance running in the browser via WebAssembly. Queries run in milliseconds with zero network round-trips after the initial load.

```
browser
  └── DuckDB WASM (web worker)
        └── reads sales_by_licensee.parquet
        └── reads sales_by_city.parquet
              └── results → React state → charts
```

## Structure

```
frontend/
├── public/
│   └── data/
│       ├── sales_by_licensee.parquet   # generated by scripts/nm_cannabis_export.py
│       └── sales_by_city.parquet
├── src/
│   ├── hooks/
│   │   └── useDuckDB.js     # initializes DuckDB WASM singleton + query helper
│   ├── components/
│   │   ├── StatCard.jsx      # summary metric cards
│   │   ├── SalesTrend.jsx    # monthly line chart
│   │   ├── Leaderboard.jsx   # top licensees table
│   │   └── CityComparison.jsx # stacked bar chart by city
│   ├── App.jsx               # layout, year filter, tab nav, stat queries
│   └── App.css               # all styles (dark industrial theme)
├── vercel.json               # COOP/COEP headers required by DuckDB WASM
└── vite.config.js            # dev server headers + duckdb-wasm exclusion
```

## Local Development

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

The Vite dev server is configured with the `Cross-Origin-Embedder-Policy` and `Cross-Origin-Opener-Policy` headers required by DuckDB WASM's SharedArrayBuffer threading. Without these, DuckDB WASM won't initialize.

---

## Deployment

Deployed on Vercel. The `vercel.json` sets the same COOP/COEP headers in production.

To deploy manually:

```bash
npm run build
```

Or just push to `main` — Vercel auto-deploys on every push.

> **Root directory:** When connecting this repo to Vercel, set the root directory to `frontend`.

---

## Updating the Data

The Parquet files in `public/data/` are static snapshots. To update them with new monthly data, run the pipeline scripts from the project root and then commit the updated files:

```bash
# from NM_Cannabis_Sales/
python scripts/nm_cannabis_export.py

git add frontend/public/data/
git commit -m "data: add <month> <year> sales data"
git push origin main
```
